# Instruções para Claude Code

As regras e limites de propriedade em `AGENTS.md` são obrigatórios para este projeto. Você trabalha na branch `feat/agents`, editando apenas `backend/agents/**`, salvo autorização humana explícita. Não desenvolver nem modificar frontend ou design.
