# Histórico do hackathon

Registros do trabalho durante o evento, mantidos para rastreabilidade. Não descrevem necessariamente o estado
atual; para isso, ver `README.md` na raiz e `docs/ARQUITETURA_COMPLETA.md`.

- `ATUALIZACAO.md`: diário de atualizações e recados entre a equipe e as IAs de programação, do mais recente
  para o mais antigo.
- `STATUS_E_PLANO_LORENZO.md`: status e plano das integrações em um momento intermediário do hackathon.
- As branches que não foram mescladas foram preservadas como tags `arquivo/*`.
