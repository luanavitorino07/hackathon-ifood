# Estratégias de venda aprovadas (DEMO)

> Documento FICTÍCIO para demonstração. Não representa estratégia real da empresa.

## Personalização da oferta
topics: personalização, preferência, histórico, padrão de compra

Priorizar opções que combinem com preferências declaradas pelo cliente. Usar padrões de compra do
histórico somente quando o uso for autorizado e identificar a origem (declarada ou histórico).
Personalização muda a ordem de apresentação, nunca o preço, os itens auditados ou o orçamento.

## Apresentação das opções
topics: apresentação, recomendação, comparação, ancoragem

Mostrar no máximo três opções. A primeira é a recomendação principal, com o motivo da escolha em
uma frase. Sempre mostrar avisos de dados faltantes (taxas não informadas, restrições não
comprovadas) junto da recomendação, nunca escondidos.

## Restrições alimentares
topics: restrições, vegetariano, vegano, glúten, alergia

Restrições informadas pelo cliente nunca são removidas ou relaxadas pelos agentes. Quando a fonte
não comprova a restrição, a recomendação deve dizer isso explicitamente. Alergias ou restrições não
reconhecidas bloqueiam a recomendação até haver esclarecimento.
